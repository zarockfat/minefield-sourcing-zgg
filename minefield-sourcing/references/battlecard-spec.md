# 作战卡写作规格

作战卡是这个 skill 的门面。它必须读起来像一份**能发给工厂和合伙人的决策文件**，不是数据截图堆砌。

完整可运行样例见 `assets/battlecard.html`（纳米双面胶带案例，含全部样式）。下面是把它复用到新品类时的规格。

---

## 视觉语言

这套设计的参照物是**专利公报 + 工业安全手册**，不是 SaaS 仪表盘。

**基底色**（保持在 4 个以内）

| 用途 | 值 |
|---|---|
| 纸底 | `#E9E7E1` |
| 次级面 | `#F2F0EA` |
| 墨色 | `#15171A` |
| 分隔线 | `#C4C1B7` |

**唯一的高饱和色是判决色**，且只用在判决相关元素上：

| 判决 | 文字 | 底 |
|---|---|---|
| 🟢 通行 | `#1F6B45` | `#DCE7DF` |
| 🟡 改设计 | `#C79412` | `#F3E9CB` |
| 🔴 否决 | `#A8251C` | `#F0DEDA` |

**字体**：正文用系统无衬线（`Helvetica Neue` / `PingFang SC` 栈），所有数字、编号、标签、图注用等宽（`ui-monospace`）。这个二分法本身就是信息：等宽 = 数据，无衬线 = 论断。

**不要做的**：圆角卡片矩阵、渐变、阴影、图标库、emoji 当装饰。判决图标用几何形状（实心圆 / 三角 / 叉），不用 emoji。

---

## 结构

固定 6 个区块，顺序不可变：

```
┌─ 文件抬头 ──────────────────────────────┐  案号 · 数据源
├─ 产品头部 ──────────────────────────────┤  品名 + 关键事实 + 判决印章（旋转 -5.5°）
├─ 结论带（墨色反白）──────────────────────┤  分数 /100 + 三句话结论
├─ 01 需求势能 ───────────────────────────┤  趋势曲线 + 4 个数据格 + 判读
├─ 02 供给结构 ───────────────────────────┤  4 个数据格 + 头部玩家表
├─ 03 专利排雷 ───────────────────────────┤  ★ 专利表（含法律状态）+ 闸门判定
├─ 04 痛点逆向 ───────────────────────────┤  认知落差对比图 + 吐槽点→设计指令表
├─ 作战参数 ──────────────────────────────┤  6 条编号指令，可直接发工厂
└─ 页脚 ──────────────────────────────────┘
```

**专利区块必须最醒目。** 它是这个 skill 与所有其他选品报告的区别所在。绝不能压缩成表格里的一行。

---

## 写作规则

**结论带**：一句话说清「能做什么 + 为什么 + 但要注意什么」。三句话，不超过 90 字。要敢下判断，不要「建议进一步观察」。

**判读段落**：每个区块末尾有一段灰字判读，作用是**解释数据意味着什么**，不是重复数据。写「这不是正在爆发的机会，是常年稳定靠运营切份额的生意」这种句子，不写「搜索量很高，竞争适中」。

**设计指令**：必须写成工厂能直接执行的参数。对照：

> ✗ 用户反映质量不好
> ✓ 腰部防滑条加宽至 3cm（对应 11% 下滑投诉）

> ✗ 提升产品力
> ✓ 包装内附 5 片测试贴 + 4 类表面适用性卡片（对应 36% 粘合强度投诉）

**专利区块的免责说明**：必须写清「品牌专利存量为 0 不等于品类无专利」，并建议正式投产前做 FTO。这是专业性的体现，也是保护用户。

---

## 图表做法

**趋势曲线**：内联 SVG，`viewBox="0 0 620 190"`。三条水平参考线 + 面积填充（`linearGradient` 从 16% 透明度到 0）+ 2px 主线 + 峰值处红点标注。X 轴只标首/中/尾三个时间点。

**认知落差对比**：两行对称条形，左绿（好评）右红（差评），中间夹一个 `vs`。这个图形专门用来呈现「同一产品评价两极」——当好评 Top1 和差评 Top1 是同一个卖点的正反面时，它就是全篇最有说服力的图。

**数据格**：`display:grid` + `repeat(auto-fit,minmax(126px,1fr))`，只用上/下边框，不用四边框。每格三行：等宽小标签 / 大数字（带小单位）/ 一行灰色注释（写明阈值或对比）。

---

## 响应式与可访问性

- ≤700px 时：头部印章左对齐、区块降为单列、数据格降为 2 列
- `prefers-reduced-motion` 时关闭条形图过渡
- 所有图表 SVG 带 `role="img"` 和 `aria-label`
- 颜色对比：正文 `#15171A` on `#E9E7E1` 远超 AA；判决色只用于短标签和大号数字
